# Application Stage Lifecycle

Applied → Screening
Screening → Shortlisted
Shortlisted → Interview Scheduled
Interview Scheduled → Interviewed
Interviewed → Offer Approval
Offer Approval → Offer Sent
Offer Sent → Offer Accepted / Offer Declined
Offer Accepted → Document Verification
Document Verification → Documents Verified / Documents Rejected
Documents Verified → Joining Letter Sent
Joining Letter Sent → Onboarded
Documents Rejected → Document Verification
